# GEOTAG — Location-based AR App

モバイルブラウザで動作する、ロケーションベースの拡張現実アプリのプロトタイプです。
住所に画像を「置く」ことができ、その場所に行くとカメラ越しに画像が浮かび上がります。

## 機能

### 2つのモード
- **AR Camera モード** — カメラを起動してロケーションベースARで登録済みの画像を空間に表示
- **Register モード** — 住所・画像・カテゴリを指定してタグを登録

### 補った機能
- **住所→緯度経度のジオコーディング** (OpenStreetMap Nominatim API)
- **「現在地を使う」ボタン** — GPSから直接座標を取得
- **画像の取り扱い** — ファイルアップロード(自動で512px縮小・JPEG圧縮) または URL指定
- **カスタムカテゴリ作成** — 名前と色を選んで新規カテゴリ作成可能
- **表示距離スライダー** — 50m〜2km の範囲で表示半径を調整
- **カテゴリ表示/非表示トグル** — メインビュー・AR HUD どちらからでも切り替え可能
- **登録一覧** — 編集はないが削除可能、サムネ・座標・カテゴリ色付きで一覧表示
- **状態の永続化** — localStorage に全データ保存
- **HUD オーバーレイ** — AR画面に十字線・ステータス・カテゴリトグル・距離スライダーを重ね表示

## 使い方

### ローカルで動かす
```bash
# HTTPSが必要なため(カメラ・位置情報の権限のため)、localhost で動かすか、
# ngrok などでトンネルを張る
python3 -m http.server 8000
# その後 http://localhost:8000 へアクセス (PCではARテストは限定的)
```

### 本番デプロイ
**HTTPS必須**です。GitHub Pages, Netlify, Vercel 等の静的ホスティングにそのままデプロイできます。

### 推奨環境
- **iOS Safari 13+** または **Android Chrome**
- カメラ・位置情報・端末方向センサーが必要
- 屋外での使用を推奨(GPS精度のため)

## デザイン
**Topographic-cyber** ── 地形図と暗い夜空、シアン+アンバー+マゼンタのアクセント、Syne(ディスプレイ)+JetBrains Mono(モノ)。
グリッド背景、座標表示、レーダーリングなど位置情報アプリらしいモチーフ。

## 技術スタック
- **A-Frame 1.4.0** — WebVR/AR フレームワーク
- **AR.js** — ロケーションベースAR (gps-camera, gps-entity-place)
- **OpenStreetMap Nominatim** — ジオコーディング(無料・API キー不要)
- **localStorage** — データ永続化
- **Vanilla JS** — 依存ライブラリは AR ライブラリのみ

## ネイティブ化したい場合
このまま **Capacitor** や **Tauri Mobile** でラップすれば、ストア配布可能なネイティブアプリになります。
さらに本格的なAR(プレーン検出、オクルージョン、影など)が必要なら、React Native + ViroReact, または Flutter + ARCore/ARKit プラグインへの移植を検討してください。

## 制約・既知の問題
- AR.jsのロケーションAR は屋内・高層階で精度が著しく落ちます(GPSの仕様上)
- iOS では DeviceOrientationEvent の許可が必要(自動でリクエストします)
- localStorage の容量制限(通常5MB)があるため、画像はJPEG圧縮しています
- 一部の古いAndroid端末では gps-entity-place の挙動が不安定です
